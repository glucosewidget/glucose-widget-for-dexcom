# GlucoseWidget for Dexcom（非公式 / Unofficial）

Dexcom の血糖値を、Windows のデスクトップの隅とタスクトレイに常駐表示する小さなウィジェットです。
範囲を外れたときは、アラート音と Windows の通知で知らせます。

**非公式アプリです。** Dexcom, Inc. が提供・承認したものではなく、Dexcom, Inc. の所有でも提携でもありません。

> **ご注意**
> - このアプリの表示やアラートを、治療の判断（インスリン量、補食など）に使わないでください。判断は必ず Dexcom 公式アプリや血糖測定器で確認し、医師の指示に従ってください。
> - このアプリは医療機器ではありません。Dexcom Share の非公式APIを使っているため、予告なく動かなくなったり、値が遅れたり欠けたりすることがあります。

> - 作者は医療関係者でも Dexcom 社の関係者でもありません。
>

## 主な機能
- 現在の血糖値（mg/dL）とトレンド（⇈ 急上昇 / ↑ 上昇 / ↗ やや上昇 / → 維持 / ↘ やや下降 / ↓ 下降 / ⇊ 急下降）、測定時刻、前回比
- 推移グラフ（1h / 3h / 6h / 12h / 24h、マウスを乗せると日時と値）
- アラート音（低血糖・高血糖・急変で音を変える。3回鳴ったら自動で止まる）と、Windows の通知
- タスクトレイに常駐（アイコンに現在値。最小化するとトレイに格納）
- 日本語 / English（Windows の表示言語で自動選択。設定でも切り替え可）
- デモモード（Dexcom にログインせず、架空のデータで動作を試せる）

単位は **mg/dL のみ** です（mmol/L には対応していません）。

## 動作環境
- Windows 10 / 11（64bit）
- センサーを着けている本人のスマホで、Dexcom アプリの「共有（Share）」がオンで、フォロワーが1人以上登録されていること（自分をフォロワーにしても構いません）。
  Dexcom G7 で確認しています。Share に対応したほかの Dexcom 製品でも動く可能性がありますが、確認していません。
- Dexcom アカウントに **メールアドレス** が登録されていること。このアプリはメールアドレスでのログインだけに対応しています（ユーザー名・電話番号ではログインできません）。

## 起動
1. `GlucoseWidgetForDexcom.exe` をダブルクリックします。インストールは不要で、好きなフォルダに置いて使えます。
   - 署名していない exe のため、初回は Windows SmartScreen の警告が出ることがあります。その場合は「詳細情報」→「実行」を選んでください。
2. 注意書きが表示されるので、内容を確認して「OK」を押します（「キャンセル」で終了します）。
3. 設定画面が開くので、**データを共有している本人の** Dexcom アカウントの **メールアドレス** と **パスワード** を入れ、**地域**（下の表）を選んで「保存」を押します。
4. 数秒で現在の血糖値が表示されます。

| 地域 | Dexcom アカウントを使っている場所 | アカウント管理サイト |
|---|---|---|
| `us` | アメリカ | [uam1.dexcom.com](https://uam1.dexcom.com) |
| `ous` | アメリカ以外（ヨーロッパなど） | [uam2.dexcom.com](https://uam2.dexcom.com) |
| `jp` | 日本 | [uam.dexcom.jp](https://uam.dexcom.jp) |

- どの地域かわからないときは、上の表のアカウント管理サイトのうち、どこに同じメールアドレスとパスワードでログインできるかで確かめられます。
- 電話番号やユーザー名で Dexcom にログインしている場合は、先に Dexcom アプリかアカウント管理サイトで、アカウントにメールアドレスを登録してください。
- メールアドレスとパスワードは半角だけ入力できます（全角を使えるのは「表示名」だけです）。
- 二重起動はしません。

### デモモード
`GlucoseWidgetForDexcom.exe --demo` で起動すると、Dexcom にログインせずに、架空の24時間データで表示・グラフ・アラート・通知を試せます。

- 画面には常に「DEMO」と表示されます。設定画面からは切り替えられません。
- 通常の起動とは別に起動できます。
- 右クリック →「デモ」→「低血糖 / 高血糖 / 急上昇をシミュレート」で、その場でアラートと通知が出ます。
- ショートカットのリンク先の末尾に ` --demo` を付けておくと便利です。

## 操作
| 操作 | 内容 |
|---|---|
| ドラッグ | 移動（位置は保存されます） |
| ダブルクリック | 今すぐ更新 |
| クリック（アラート中） | アラート音を止める |
| 右上の「–」 | 最小化（ウィンドウを隠してタスクトレイに格納） |
| 右クリック | メニュー：今すぐ更新 / 推移グラフを表示 / 表示サイズ / 設定… / 常に最前面 / Windows起動時に自動起動 / 最小化（トレイに格納） / 終了 |
| トレイアイコンを左クリック | ウィンドウの表示 / 非表示 |
| トレイアイコンを右クリック | 現在の血糖値と、ウィンドウの右クリックと同じメニュー |

## 表示
- 上部に表示名（設定で空にすると、メールアドレスを伏せ字で表示）
- 色：50 mg/dL 未満は赤、下限以下はオレンジ、上限以上は黄色
- 最新の値から15分以上たつと灰色になり、「⚠ データが古い」と表示（この間はアラートを鳴らしません）
- 表示サイズ：小 / 中 / 大 / 特大
- トレイアイコン：最小化の有無に関係なく常に表示。アイコンに現在値（色は本体と同じ考え方で、範囲内は緑）

## アラート
- 設定した「この値以下で鳴らす」「この値以上で鳴らす」になったら鳴ります（低血糖は速い高音、高血糖はゆっくりした低音）。
- 範囲内でも、急上昇・急下降で鳴らすこともできます（「急上昇・急下降でも鳴らす」）。
- 音のパターンを3回鳴らしたら自動で止まります。アラート中は外枠が赤く点滅します。
- 同じ状態が続く間は、設定した間隔（初期値15分）ごとに鳴らし直します。

### 通知
- 「Windows の通知でも知らせる」がオン（初期値）だと、Windows の通知も出ます。
- 一度通知を出すと、Windows の「設定 → システム → 通知 → アプリやその他の送信者からの通知」に「GlucoseWidget for Dexcom」が追加され、このアプリだけオン / オフできます。

### 音量
- 設定画面の「アラート音の音量」スライダー（0〜100%）で調整します。Windows の音量ミキサーにあるこのアプリの音量と連動していて、どちらで変えても同じ値になります（動かした時点で反映され、保存は不要です）。
- 0% やミュートにすると、アラート音は聞こえません。音を止めたいときは「アラートを鳴らす」をオフにしてください。

## データの取得タイミング
- Dexcom のセンサーは約5分ごとに測定します。「最新の測定時刻＋5分」を少し過ぎたら取りに行き、まだ届いていなければ30〜60秒後にもう一度取りに行きます。
- 24時間分を取るのは、起動時・アカウント変更時・長い中断（スリープからの復帰など）のあとだけです。普段は直近の数件だけを取ります。
- 通信エラーが続いたときは、間隔を 1→2→4→8→15分 と延ばします。

## データの扱い
- 通信先は Dexcom の Share サーバー（HTTPS）だけです。利用状況などを外部に送ることはありません。
- 血糖値はメモリ上にだけ持ち、ディスクには保存しません。
- パスワードは Windows の資格情報マネージャーに保存し、設定ファイルには書きません。

| 内容 | 保存場所 |
|---|---|
| 設定 | `%APPDATA%\GlucoseWidget\config.json` |
| パスワード | Windows 資格情報マネージャー（`GlucoseWidget`） |
| 通知用のアイコン | `%APPDATA%\GlucoseWidget\icon.png` |
| アラート音（起動中に自動生成） | `%TEMP%\GlucoseWidget\` |
| 通知の送り主の登録 | レジストリ `HKCU\Software\Classes\AppUserModelId\GlucoseWidget` |
| 自動起動 | スタートアップフォルダの `GlucoseWidget.vbs` |

## 自動起動
右クリック →「Windows起動時に自動起動」で切り替えます。exe を移動・改名しても、次に起動したときに登録先が自動で更新されます。

## アンインストール
1. 自動起動をオンにしていた場合は、右クリック →「Windows起動時に自動起動」をオフにします。
2. 右クリック →「終了」で終了し、exe を削除します。
3. `%APPDATA%\GlucoseWidget` と `%TEMP%\GlucoseWidget` のフォルダを削除します。
4. 「資格情報マネージャー」→「Windows 資格情報」から `GlucoseWidget` を含む項目を削除します。
5. 通知設定の一覧からも消す場合は、レジストリの `HKCU\Software\Classes\AppUserModelId\GlucoseWidget` と `HKCU\Software\Microsoft\Windows\CurrentVersion\Notifications\Settings\GlucoseWidget` を削除します。

## 困ったとき
| 症状 | 確認すること |
|---|---|
| 「ログイン失敗」と出る | 地域のアカウント管理サイト（上の表）に同じメールアドレスとパスワードでログインできるか。共有がオンでフォロワーが1人以上いるか。地域が合っているか |
| 「試行回数オーバーでロック中」と出る | しばらく待ってから、設定画面で「保存」を押し直してください（失敗が続くとアカウントが一時的にロックされるため、アプリは自動では再試行しません） |
| 設定画面が開き、ログインしない | 以前の版でユーザー名・電話番号を保存していた場合です。メールアドレスとパスワードを入れ直してください |
| 「データが古い」と出る | センサーを着けている人のスマホで Dexcom アプリが動いていて、ネットにつながっているか |
| 通知が出ない | Windows の「設定 → システム → 通知」で、全体の「通知」とこのアプリがオンか、「応答不可」がオフか |
| 音が聞こえない | 設定画面の音量が 0% やミュートになっていないか。「アラートを鳴らす」がオンか |
